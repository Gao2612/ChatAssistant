## 准备

- 安装包：`windows/lite/dist-release/ChatAssistantLite-Setup.exe`

- 不保存真实聊天内容、不把截图外传；发送测试只在明确同意时进行

## 1. 连接与镜像预览

1. 打开助手 → 设置 → 刷新窗口 → 选中微信窗口 → 连接所选窗口
2. 预期：聊天页显示“正在本地识别 · 中央实时画面”，原生微信可正常拖动
3. 拖动助手窗口边缘缩放：原生微信窗口**大小/位置不应变化**
4. 勾选“停靠微信窗口”再试一次：应变为应用管理停靠；取消勾选恢复正常

## 2. 托盘隐藏读取

1. 保持已连接，点击微信关闭按钮使其隐藏到托盘
2. 预期：助手状态显示“微信在运行但窗口不可见/从托盘打开”，不会重复启动微信
3. 点击助手“启动微信”或从托盘恢复：原窗口恢复，识别继续
4. 可选：恢复后查看识别文字是否更新

## 3. 自动查找对话

1. 设置 → 自动操作 → 输入“田子夜” → 自动查找并切换对话
2. 预期：微信切到田子夜，助手显示“已切换至目标对话”，**不发送任何消息**
3. 已知限制：名字“郜亚禹”在当前 OCR 下会被误识（部亚禹一类），会安全失败并 ESC；
   不会切换到错误会话

## 4. 建议生成与发送（需要真实模型额度）

1. 重填 DeepSeek API Key（或恢复 ChatGPT 套餐额度）；设置页会提示当前 Key 是否为占位值
2. 连接微信并保持一个会话 → 等待分析结果（3 条建议）
3. 勾选“允许把建议发送到微信”→ 点击某条建议的“发送到微信”→ 二次确认
4. 预期：发送前校验会话标题；发送后提示“输入框已清空 + 气泡出现”；失败会明确报错且不重复发
5. 若只想验证界面而不真正发送，可只看按钮是否出现及校验提示，不点击确认

## 5. 历史与专属风格

1. 历史页导入一份**测试**聊天记录（HTML/PDF/文本）
2. 选择联系人 → 关联当前微信会话 → 触发分析 → 点“参考历史 N 条（点击查看）”
3. 点“从聊天记录生成专属风格” → 查看 prompt_style（300–600 字）与显示报告（800–1500 字）
4. 预期：不会使用未关联联系人的历史；报告只基于导入内容

## 6. 多窗口与弹窗（T10/T12）

1. 若你有两个微信窗口/账号：设置勾选“后台监控其他正常微信窗口”（默认关闭，最多 2 个）
2. 预期：其他窗口不被移动、不被键入；活动窗口优先；关闭一个不影响另一个
3. 弹窗/最小化：让微信出现真实弹窗或最小化，助手不应误读/误发，恢复后继续

## 7. 双窗口 30 分钟稳定性

- 两个微信正常窗口同时存在 30 分钟，观察助手 CPU/内存/句柄是否持续上涨、是否串会话
- 记录任务管理器截图或数字（无需聊天内容）

## 8. 干净 Windows VM（可选但建议）

- 在干净 VM 安装 0.5.3 → 启动自检 → 卸载 → 保留数据/重装检查
- 已有脚本：`windows/lite/tools/verify_install.ps1`
