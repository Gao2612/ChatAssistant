# Windows Lite 0.2 本机验证记录

日期：2026-10-17。分支：`feat/windows-lite`。源码位于 `windows/lite/`。

## 已验证

- `python -m unittest discover -s tests -q`：46 项通过，含窗口身份、停靠几何、HTML/PDF 本地导入、授权回调及 UI 状态。
- 官方微信 `C:\Program Files\Tencent\Weixin\Weixin.exe`：按完整路径发现 1 个已登录主窗口。受限测试终端一度看不到进程；在实际用户桌面权限下可发现。这是测试进程可见性差异，不是用户未开微信。
- 本地采集取得画面帧及 OCR 快照，快照包含 11 条当前可见消息。测试只输出数量，不保存或打印真实聊天文字。
- 实际窗口停靠：助手在前台时，中央开口的鼠标命中对象是官方微信原生窗口；切换到设置页或最小化助手时微信最小化，返回聊天页/恢复助手时重新停靠，助手退出后微信恢复原位置。另一轮测试中助手未获得前台焦点，屏幕命中测试返回了覆盖它的其他窗口，因此鼠标命中结论限定在助手位于前台的情形。旧 `SetParent` 子窗口方案的单击/滚轮故障不代表本顶层停靠方案通过了全部交互验收。
- ChatGPT 官方网页授权完成，本机账号模型目录返回 7 个模型；以完全合成的对话请求实际模型接口，成功得到 3 条回复建议。令牌通过 Windows DPAPI 保存，测试未打印令牌或模型正文。初次授权 5 分钟回调超时造成浏览器显示 `127.0.0.1 拒绝连接`，已将等待时间改为 15 分钟并重试成功。
- 便携版构建后通过无界面启动检查；测试安装包解包完毕后，安装目录 EXE 使用真实 Windows 图形后端以 `--smoke` 正常退出。测试安装使用无卸载项、无快捷方式的验证配置，放在仓库忽略的 `test-output/installed`。
- 最终正式安装器于本日重新全量构建成功。构建脚本已启用 PyInstaller `--clean`，避免增量缓存复用旧授权/界面模块；包内字节码确认包含授权完成后切换 ChatGPT 模型、15 分钟授权回调等待。安装器大小 100101701 字节，SHA-256：`BE180E6947B3BB849E80F7EC4F3EF2F099796A2240CCFCF65046BF5FE91B4912`。最新便携版的 `--smoke` 随构建通过。
- 46 项测试此前在允许本地回环的环境中通过；本次受限终端复跑时，45 项非回环测试通过，唯一的本地 HTTP 流测试因终端回环连接限制失败。这不代表该用例在产品运行环境失败。

## 尚未验证

- 中央微信的真实单击选会话、鼠标滚轮、中文输入法、扫码登录、多开和各类弹窗尚未逐项人工验收；中央鼠标命中微信只能证明输入路由，不证明每项行为正常。
- 没有提供真实 ExportWeChat HTML 样本；目前 HTML/PDF 保守提取并加密保存全部文字片段，不能保证从任意导出模板还原发送人和精确时间。扫描型 PDF 需要先有文字层。
- 历史报告为覆盖所有导入片段的本地证据整理与统计，不是模型对全部历史内容形成的客户人格判断。
- 正式用户安装器的升级、卸载、数据保留仍未实测；无卸载项验证安装和启动已通过。
- 当前最终安装器尚未在真实用户安装流程中执行；上述验证配置安装和启动针对此前同布局的安装包。真实微信到云模型的完整自动分析链路也尚未在最终安装器内复测。

## 使用边界

助手不修改微信父级/样式，不直接读取微信数据库，不自动发送消息。实时自动分析在模型就绪且用户开启该设置时，会将当前可见对话文字发送给所选模型；历史导入和本地报告不会自动上传。实际套餐模型和额度以官方授权返回为准，不能把 Codex 桌面当前模型或会话令牌当作本应用已自动继承。
