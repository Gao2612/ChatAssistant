## 已确认需求
- 当前需求包含官方微信聊天在中央可见且可交互、实时自动判断、右侧不压缩主视图的建议栏，以及按联系人导入历史文件。本版采用不修改父级与窗口样式的原生顶层停靠，停靠失败显示只读镜像；已验证鼠标命中原生微信窗口，完整交互仍需逐项验证。
- 可发现多个微信窗口，一次由助手选择一个采集目标；用户手动发送微信消息。
- Plus/Pro 或 Codex 额度通过官方本地 OSS ChatGPT plan usage 流程单独授权；模型来自账号目录。此应用不镜像 Codex 桌面当前会话选择。
- HTML/PDF 历史文字可按手动绑定的账号与联系人导入加密本地库、浏览、检索并生成覆盖所有已导入片段的保守离线报告。未提供 ExportWeChat HTML 样本，发送人/时间不保证准确还原；离线报告不等于模型客户画像。
- 便携目录在 `windows/lite/dist-release/ChatAssistantLite`；最终安装器在 `windows/lite/dist-release/ChatAssistantLite-Setup.exe`，SHA-256 见本机验证记录。上一版正式安装器编译成功，但沙箱拒绝写入 HKCU 卸载注册表；0.2 版完整安装仍需验证。

## 推荐路线
独立 `windows/lite/` 工程，参考 jev-chat-windows 的本地 OCR/气泡定位模块；通过完整官方 exe 路径筛选微信窗口。历史通道采用安全纯文本 HTML/PDF 解析、Windows DPAPI 加密本地库，不直接读取微信数据库。
