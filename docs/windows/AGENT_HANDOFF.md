## 已确认需求
- Windows exe 安装包，安装后无需开发环境。
- 官方微信扫码登录与聊天界面嵌入软件内部。
- 多微信账号登录与切换。
- 实时判断对话、提供回复建议；用户确认发送。
- 独立历史分析任务界面：客户画像、关系趋势、聊天统计。
- 首版导入 ExportWeChat HTML，并可复用软件本地保存的聊天记录。

## 推荐路线
独立 windows/ 工程，参考 jev-chat/jev-chat-windows 的采集和分析模块。
先验证窗口托管、实际多实例与嵌入后采集，再实现产品。
历史通道采用安全 HTML 解析 + SQLite + 持久化任务 + 证据报告。
当前不需要直接读取微信数据库。

## 不可误读
- 本方案不代表这些功能已经存在或测试通过。

- ExportWeChat 具体仓库、版本和样本尚未提供，不能猜测 DOM。
- 已记录微信 4.1.15.53、Windows 构建 26200.9457；其它版本与后台多账号采集要求尚待确认。
- 名称不能作为账号或会话的唯一 ID；重复消息不能仅按正文去重。
- 不上传真实聊天、API 密钥或账号资料；分析云模型发送范围必须明确。
