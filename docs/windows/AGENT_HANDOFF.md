## 已确认需求
- Windows exe 安装包，安装后无需开发环境。
- 官方微信扫码登录与聊天界面嵌入软件内部。
- 多微信账号登录与切换。
- 实时判断对话、提供回复建议；用户确认发送。
- 独立历史分析任务界面：客户画像、关系趋势、聊天统计。
- 首版导入 ExportWeChat HTML，并可复用软件本地保存的聊天记录。

## 推荐路线
独立 windows/ 工程，以 crush 的 Electron 与 TypeScript 源码为桌面壳、
导入和分析模块的开发基础，具体映射见源码参考包说明。
实时采集参考 jev-chat/jev-chat-windows 的 WGC/OCR 思路，需独立验证。
微信嵌入实验因白屏和恢复故障暂停，不再作为导入与历史分析的前置阻塞。
历史通道采用安全 HTML 解析 + SQLite + 持久化任务 + 证据报告。
当前不需要直接读取微信数据库。
